# MediVault Frontend

React SPA for tracking and comparing your own blood test results over time. Talks to [`medivault-backend`](../medivault-backend) over REST. See [`CONTEXT.md`](CONTEXT.md) for the domain vocabulary and [`docs/adr/`](docs/adr) for architecture decisions.

**Stack:** Vite, React (with React Compiler), TypeScript (strict), Tailwind CSS, shadcn/ui, TanStack Router, TanStack Query, Vitest + React Testing Library, Playwright.

## Setup

Requires Node 24 and [pnpm](https://pnpm.io).

```bash
pnpm install
cp .env.example .env   # optional; defaults work with a local backend
```

| Variable            | Default                     | Description                             |
| ------------------- | --------------------------- | --------------------------------------- |
| `VITE_API_BASE_URL` | `http://localhost:3000/api` | Base URL of the `medivault-backend` API |

## Scripts

| Command             | What it does                                            |
| ------------------- | ------------------------------------------------------- |
| `pnpm dev`          | Start the dev server on http://localhost:4200           |
| `pnpm build`        | Typecheck and produce a static bundle in `dist/`        |
| `pnpm preview`      | Serve the production build locally                      |
| `pnpm lint`         | Run ESLint (zero warnings allowed)                      |
| `pnpm lint:fix`     | Run ESLint with autofix                                 |
| `pnpm format`       | Format everything with Prettier                         |
| `pnpm format:check` | Check formatting without writing                        |
| `pnpm typecheck`    | Run `tsc` without emitting                              |
| `pnpm test`         | Run unit/integration tests (Vitest)                     |
| `pnpm test:watch`   | Run Vitest in watch mode                                |
| `pnpm test:e2e`     | Build, serve, and run Playwright smoke tests (Chromium) |

First-time e2e setup: `pnpm exec playwright install --with-deps chromium`.

A Husky pre-commit hook runs lint-staged (ESLint + Prettier on staged files).

## Project layout

```
src/
  main.tsx     Entry point
  app.tsx      Providers + router (composition root)
  routes/      File-based routes (TanStack Router)
  features/    One folder per feature, added by later topics
  components/  Shared components (shadcn/ui components live in components/ui)
  lib/         Utilities, env access, query client (lib/auth: reserved for the in-memory token module, ADR-0002)
  test/        Vitest setup
e2e/           Playwright tests
```

Layer import rules are enforced by ESLint — see [ADR-0007](docs/adr/0007-module-boundaries.md).

Imports use the `@/` alias for `src/`. `src/routeTree.gen.ts` is generated by the TanStack Router plugin — commit it, don't edit it.

API types are hand-written ([ADR-0003](docs/adr/0003-type-safety-strategy.md)): keep them thin and next to the feature that uses them (e.g. `src/features/<feature>/types.ts`), named per the vocabulary in `CONTEXT.md`.

Add shadcn/ui components with `pnpm dlx shadcn@latest add <component>`.

## CI

GitHub Actions runs install → lint → format check → typecheck → unit tests → Playwright smoke test on every PR to `master`. The build is a plain static bundle deployable to any host.
